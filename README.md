# ak-engine
An engine for ak related extensions

## Development

Required Go version: `1.25.6`.

Standalone setup from a fresh clone:

```bash
git clone git@github.com:david22573/ak-engine.git
cd ak-engine
GOWORK=off go mod download
make verify
```

The first dependency download needs network access unless the module cache is already populated. After dependencies are available, `make verify` runs local formatting, vet, test, and build checks with `GOWORK=off`.

`go.work` is optional for local multi-repository development and is not required to build or test this repository. `ak-engine` does not import `ak-rif`; it exchanges RIF-compatible JSON artifacts (`*.research.lock`, `*.research_audit.json`, and optional `*.promotion_packet.json`) through the wire schema in `internal/rifbridge`.

## Research Integrity Framework (RIF)

`ak-engine` emits RIF-compatible JSON artifacts to ensure that research candidates are audited, reproducible, and evaluated against strict integrity standards without requiring a sibling `ak-rif` checkout.

### Universe Metadata & Survivorship Bias

To protect against survivorship bias, `ak-engine` extracts universe metadata from the `dataset_manifest.json` generated by `ak-historian`.

The metadata flow is as follows:
1. **Universe Manifest (`universe_manifest.json`)**: Contains point-in-time rules, symbols, and delisted inclusion status.
2. **Dataset Manifest (`dataset_manifest.json`)**: Embeds the universe manifest rules and hashes during dataset generation.
3. **RIF Evaluation**: When evaluating a candidate in `ak-engine`, it reads the `dataset_manifest.json` and embeds the following into `research.lock` and `research_audit.json`:
   - `UniversePolicy` (e.g., `POINT_IN_TIME_EXCHANGE_UNIVERSE`, `EXPLICIT_SYMBOL_LIST`)
   - `SurvivorshipBiasRisk` (`LOW`, `MEDIUM`, `HIGH`)
   - Universe hashes for reproducibility

### Promotion Gating

Candidates are **blocked** from promotion to `validated_research_lead` if:
- `UniversePolicy` is `EXPLICIT_SYMBOL_LIST`, `CURRENT_ACTIVE_SYMBOL_LIST`, or `UNKNOWN` ( inherently risky for survivorship bias).
- `UniversePolicy` is `LOCAL_DATA_DISCOVERED_SYMBOLS` but the survivorship bias risk is not `LOW` (requires proof of point-in-time fidelity).

This durable foundation prevents AK Universe from falsely treating a current active symbol list as survivorship-bias-free historical research.
